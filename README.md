# Flexbox 연습장

CSS Flexbox를 눈으로 익히는 인터랙티브 학습 도구입니다. 빌드 도구나 의존성 없이 HTML·CSS·바닐라 JS로만 만들어졌습니다.

## 구성

| 탭 | 내용 |
| --- | --- |
| 플레이그라운드 | 컨테이너·아이템 속성을 직접 조작하고 결과 CSS/HTML을 실시간으로 확인 |
| 속성 설명 | 12가지 Flexbox 속성의 값별 시각 데모. 주축 방향에 따라 결과가 달라지는 속성은 `row`/`column` 데모를 모두 제공 |
| 실전 예제 | 네비게이션 바, 카드 그리드 등 실제 레이아웃 패턴 |
| 챌린지 | 목표 레이아웃을 보고 속성을 맞히는 문제 |

## 로컬에서 실행

정적 파일이라 아무 정적 서버로나 열 수 있습니다.

```bash
python3 .claude/serve.py 7788
```

`http://localhost:7788` 접속. 같은 Wi-Fi의 태블릿·폰에서도 `http://<맥의 IP>:7788`로 열립니다.
